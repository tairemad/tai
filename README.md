# Tairema Dailey — Portfolio

Personal portfolio site for Tairema Dailey, Front-End Software Engineer. Built with React 19 and Vite, deployed to Netlify.

## Stack

- [React 19](https://react.dev)
- [Vite](https://vitejs.dev)
- [React Router](https://reactrouter.com)
- [styled-components](https://styled-components.com)
- [MUI Icons](https://mui.com/material-ui/material-icons/)

## Commands

```bash
npm start        # dev server at http://localhost:5173
npm run build    # production build → dist/
npm run preview  # preview production build locally
npm test         # run tests
```

## Deployment

Deployed via Netlify. The `netlify.toml` configures the build command, publish directory (`dist/`), and SPA redirect rule.
